# 応用情報技術者試験 過去問動画一覧

石田宏実の情報処理技術者試験講座の公開再生リストから作成した非公式リンク集。
午前・午後のタブ、試験回の行、問題番号の列でYouTube動画を探せます。

- 個別解説を優先。まとめ動画のみがある問題は、その動画の先頭へリンク。
- 問題番号を特定できない総合の解答速報は、試験回の下に別リンクとして掲載。
- 動画URLを確認できないセルは「未確認」と表示し、推測のリンクを付けません。
- 試験と関係のない動画は除外。その他の再生リストはページ下部に掲載。
- ビルド不要。HTML / CSS / JavaScript / JSONのみで動作します。

## ローカル表示

```sh
python3 -m http.server 8000
```

## データ更新

ブラウザの再生リスト一覧から、通常の再生リストに加えて「コース」形式のURLも取得してください。
2026年7月版yt-dlpでは、チャンネルの `/playlists` 一括取得がコースを読み飛ばすため、これだけで完全と判断しないでください。
各再生リストは `--flat-playlist --dump-single-json --extractor-args 'youtube:lang=ja'` で取得できます。
チャンネルの `/videos`・`/shorts`・`/streams` も取得し、取りこぼしを照合してください。

監査用カタログ `scripts/source-videos.json` に動画ID・日本語タイトル・再生リスト情報をまとめてあります。
カタログを更新したら次を実行します。

```sh
python3 scripts/build-data.py
```

問題番号のある解答速報も各問題に対応づけます。通常の個別解説があればそちらを優先します。
確認できていない箇所に推測したURLや別問題のURLは付けません。
